# ⚡ Workspace Hub (デスクトップ・ホームランチャー)

Windowsデスクトップ上で使いたいツール（アプリ、Webサイト、フォルダ、スクリプト等）を登録し、**ワンボタンで任意のディスプレイ・任意のレイアウト（左右分割、全画面、4分割、カスタム座標など）で一括起動・配置できるホームアプリ**です。

**ZIPで送って解凍するだけで、どんなPC環境（Windows 10 / 11、シングル画面・マルチ画面）でもそのまま使用できる完全ポータブル仕様**になっています。

---

## 🚀 クイックスタート（初めて使う方へ）

### ステップ 1: ZIPを解凍する
受け取った `shortcut.zip` を右クリックし、**「すべて展開...」** を選んでお好みの場所（デスクトップ、ドキュメント、Cドライブ等）に解凍します。
※ZIPのまま中身を開かず、必ず「すべて展開」してください。

### ステップ 2: （初回のみ）ブロック解除を実行
インターネット経由（メール、Discord、Slack、Googleドライブ等）で受け取ったファイルには、Windowsのセキュリティ制限（SmartScreen保護 / Mark-of-the-Web）が付与されることがあります。
フォルダ内の **`00_最初に実行（ブロック解除）.bat`** をダブルクリックして実行してください。ワンクリックですべての制限が自動解除されます。

### ステップ 3: ホームアプリを起動
**`01_ホームアプリを起動.bat`** または **`WorkspaceHub.exe`** をダブルクリックして起動します！

> 💡 **おすすめの初回体験:**
> 画面上部のプロファイル切り替えで **「🌟 標準アプリ（全環境動作デモ）」** を選択し、紫色の **「⚡ すべてのツールを任意の形で一括起動」** を押してみてください。
> Windows標準の「メモ帳（左画面）」「Google検索（右上）」「電卓（右下）」が自動で一瞬にして整列配置されるのを体験いただけます！

## 🌟 主な特徴

1. **ワンボタン一括起動**
   - 登録されたすべてのツールを順番に起動し、あらかじめ設定した画面位置・サイズへ自動的に吸着配置します。
2. **どんな環境でも動くポータブル設計**
   - **ユーザー環境の自動吸収**: 設定ファイルに別PCのユーザーパスが含まれていても、現在のPCのユーザー環境（`%USERPROFILE%`, `%APPDATA%`, `%LOCALAPPDATA%`）へ自動フォールバック。
   - **モニター構成の自動適応**: 送信元のマルチモニター（2画面や負の座標）の設定が残っていても、受け取った側のモニター数・解像度を自動認識し、画面外に飛ぶことなく自動で安全に画面内へ収めます。
   - **ブラウザ自動検出**: Chrome, Edge, Brave, Firefox などを自動検出し、独立個別ウィンドウとして配置。万が一未検出の場合でも既定のブラウザで確実に開きます。
   - **外部ランタイム不要**: Windows標準の .NET Framework のみで動作し、Node.js や Python などのインストールは一切不要です。
3. **任意の形で立ち上げる多彩なレイアウト**
   - 🖥️ **全画面 (Maximized)**
   - ◀️ **画面 左半分 (Left 50%)** / ▶️ **画面 右半分 (Right 50%)**
   - ⬆️ **画面 上半分 (Top 50%)** / ⬇️ **画面 下半分 (Bottom 50%)**
   - ◰ **左上 1/4** / ◳ **右上 1/4** / ◱ **左下 1/4** / ◲ **右下 1/4**
   - 🎯 **画面 中央 (Center 70%)**
   - 📐 **カスタム座標・サイズ (X, Y, 幅, 高さ)**
4. **マルチモニター完全対応**
   - メインモニターだけでなく、接続されている各サブモニターを指定して配置可能（タスクバーの領域を自動考慮）。
5. **✨「現在のウィンドウから取得」自動キャプチャ機能**
   - デスクトップ上で開いているウィンドウを選んでボタンを押すだけで、位置やサイズ、対象モニターを自動取得します。
6. **複数プロファイル管理**
   - 「💻 開発・作業」「📝 リサーチ・調査」「🌟 標準アプリ（デモ）」など、作業目的に応じて複数のツールセットを切り替え可能。
7. **デスクトップへのショートカット作成**
   - `02_デスクトップにショートカット作成.bat` を実行するだけで、デスクトップ上に美しい稲妻アイコン（⚡）のショートカットが自動生成されます。
8. **📌 タスクバーへのピン留め対応**
   - `03_タスクバーにピン留め設定.bat` を実行すれば、タスクバーへのピン留め手順が案内され、タスクバーからいつでもワンクリックで一括起動できます。

## 🚀 使い方

### 1. ホームアプリを起動する
- `01_ホームアプリを起動.bat` または `WorkspaceHub.exe` をダブルクリックして起動します。

### 2. ワンボタンで一括起動する
- 最上部にある紫色の大きなボタン **「⚡ すべてのツールを任意の形で一括起動」** をクリックします。
- 登録されたツールが順番に立ち上がり、指定した位置・サイズに自動整列されます。

### 3. ツールの追加・レイアウト設定
- **「＋ ツールを追加」** をクリックします。
- **ツール名**: 表示名（例: VS Code、Google Chromeなど）
- **起動ファイル・URL・コマンド**:
  - `参照...` ボタンから `.exe` や `.lnk`（ショートカット）を選択。
  - またはWebサイトのURL（例: `https://www.google.com`）を入力。
- **配置先モニター**: メインモニター または サブモニターを選択。
- **配置レイアウト**: 左半分、右半分、全画面、1/4分割などを選択。
- **開いているウィンドウから位置を自動取得**:
  - デスクトップ上で好みの位置に置いたアプリがある場合、このボタンを押して一覧から選ぶだけで、位置・サイズが自動入力されます。

### 4. 個別操作
- 各ツールカードの **「▶ 起動」**: そのツールだけを単体で起動＆配置。
- 各ツールカードの **「📐 配置」**: すでに起動しているツールの位置を再整列。
- **「✏️ 編集」** / **「🗑️ 削除」**: 設定の変更や削除。

### 5. デスクトップショートカットを作成する
- `02_デスクトップにショートカット作成.bat`（またはアプリ内の「📌 デスクトップにショートカット作成」ボタン）を実行すると、デスクトップ上に `⚡ ワークスペース一括起動.lnk` が作成されます。
- これをダブルクリックすれば、ホーム画面を開くことなく、ワンクリックで全ツールが一括配置されます。

## 🛠️ 再ビルド方法（カスタマイズ時）

ソースコード `WorkspaceHub.cs` や `LaunchWorkspace.cs` を編集した場合、以下のいずれかを実行するだけで再コンパイルできます。

- `build.bat` をダブルクリック
- または PowerShell で `.\build.ps1` を実行
