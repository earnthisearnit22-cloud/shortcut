# ⚡ Workspace Hub (デスクトップ・ホームランチャー)

Windowsデスクトップ上で使いたいツール（アプリ、Webサイト、フォルダ、スクリプト等）を登録し、**ワンボタンで任意のディスプレイ・任意のレイアウト（左右分割、全画面、4分割、カスタム座標など）で一括起動・配置できるホームアプリ**です。

**ZIPで送って解凍するだけで、どんなPC環境（Windows 10 / 11、シングル画面・マルチ画面）でもそのまま使用できる完全ポータブル仕様**になっています。

---

## 🚀 クイックスタート（初めて使う方へ）

### ステップ 1: ZIPを解凍する
受け取った `shortcut.zip` を右クリックし、**「すべて展開...」** を選んでお好みの場所（デスクトップ、ドキュメント、Cドライブ等）に解凍します。
※ZIPのまま中身を開かず、必ず「すべて展開」してください。

### ステップ 2: （初回のみ）ブロック解除を実行
インターネット経由（メール、Discord、Slack、Googleドライブ等）で受け取ったファイルには、Windowsのセキュリティ制限（SmartScreen保護 / Mark-of-the-Web）が付与されることがあります。
フォルダ内の **`00_最初に実行（ブロック解除）.bat`** をダブルクリックして実行してください。ワンクリックですべての制限が自動解除されます。

### ステップ 3: ホームアプリを起動
**`01_ホームアプリを起動.bat`** または **`WorkspaceHub.exe`** をダブルクリックして起動します！

> 💡 **おすすめの初回体験:**
> 画面上部のプロファイル切り替えで **「🌟 標準アプリ（全環境動作デモ）」** を選択し、紫色の **「⚡ すべてのツールを任意の形で一括起動」** を押してみてください。
> Windows標準の「メモ帳（左画面）」「Google検索（右上）」「電卓（右下）」が自動で一瞬にして整列配置されるのを体験いただけます！

## 🌟 主な特徴

1. **ワンボタン一括起動＆吸着配置**
   - 登録されたすべてのツールを順番に起動し、あらかじめ設定した画面位置・サイズへ自動的に吸着配置します。
2. **📸 現在の画面配置から丸ごとプロファイル新規作成（一発スナップショット）**
   - 好きなようにデスクトップ上にウィンドウを並べて **「📸 画面から新規作成」** ボタンを押すだけで、開いている全アプリの位置・サイズ・モニターを自動認識して新しいプロファイルが一瞬で完成します！
3. **⌨️ グローバルホットキー対応（作業中も手ぶらで整列）**
   - `Ctrl + Alt + W`: いつでもどこからでも全ツールを一括起動＆定位置に再整列！
   - `Ctrl + Alt + H`: 全ツールを一括最小化（離席・デスク片付け）/ もう一度押すと元の位置へ一括復元！
4. **🧹 一括片付け＆一括終了**
   - 作業終了時や休憩時に、登録ツールをワンクリックで **「一括最小化/復元」** または **「一括終了」** できます。
5. **🚀 タスクトレイ常駐＆PC起動時スタートアップ**
   - 閉じる（×）ボタンを押してもタスクトレイ（画面右下の通知領域）にスマートに常駐。
   - 「🚀 PC起動時に常駐」にチェックを入れるだけで、ログイン時にバックグラウンドでスタンバイ。タスクトレイの稲妻アイコンを右クリックすれば、いつでもプロファイル切り替えや一括起動が可能です。
6. **どんな環境でも動くポータブル設計**
   - **ユーザー環境の自動吸収**: 設定ファイルに別PCのユーザーパスが含まれていても、現在のPCのユーザー環境（`%USERPROFILE%`, `%APPDATA%`, `%LOCALAPPDATA%`）へ自動フォールバック。
   - **モニター構成の自動適応**: 送信元のマルチモニター（2画面や負の座標）の設定が残っていても、受け取った側のモニター数・解像度を自動認識し、画面外に飛ぶことなく自動で安全に画面内へ収めます。
   - **ブラウザ自動検出**: Chrome, Edge, Brave, Firefox などを自動検出し、独立個別ウィンドウとして配置。
   - **外部ランタイム不要**: Windows標準の .NET Framework のみで動作し、追加インストールは一切不要です。
7. **多彩なレイアウト**
   - 🖥️ 全画面 / ◀️ 左半分 / ▶️ 右半分 / ⬆️ 上半分 / ⬇️ 下半分 / ◰◳◱◲ 4分割 / 🎯 画面中央 / 📐 カスタム座標
8. **デスクトップへのショートカット＆タスクバーピン留め**
   - `02_デスクトップにショートカット作成.bat` でデスクトップ上に稲妻アイコンのショートカットを即座に作成できます。

## 🚀 使い方

### 1. ホームアプリを起動する
- `01_ホームアプリを起動.bat` または `WorkspaceHub.exe` をダブルクリックして起動します。

### 2. ワンボタンで一括起動する
- 最上部にある紫色の大きなボタン **「⚡ すべてのツールを任意の形で一括起動」** をクリックします。
- 登録されたツールが順番に立ち上がり、指定した位置・サイズに自動整列されます。

### 3. デスクトップから丸ごとプロファイルを作る（超おすすめ！）
1. お好みのアプリ（ブラウザ、VS Code、メモ帳、Discordなど）を起動し、好みの位置・サイズに配置します。
2. 画面上部の **「📸 画面から新規作成」** ボタンをクリックします。
3. デスクトップ上で開いているウィンドウが一覧表示されるので、登録したいアプリにチェックを入れて「作成」を押します。
4. これだけで、現在の画面配置がそのまま新規プロファイルとして保存されます！

### 4. 日常のスマート操作
- **整列の復元**: 作業中にウィンドウの位置が乱れたら、`Ctrl + Alt + W` を押すか **「📐 起動中ツールを再配置」** を押せば一瞬で定位置に戻ります。
- **一括片付け**: 離席時や別作業に移る際は、`Ctrl + Alt + H` または **「🧹 最小化/復元」** を押すと一瞬でデスクが片付きます。もう一度押すと元の配置に復元されます。
- **一括終了**: **「❌ 一括終了」** を押せば、登録されているツールをまとめて安全に閉じることができます。

ソースコード `WorkspaceHub.cs` や `LaunchWorkspace.cs` を編集した場合、以下のいずれかを実行するだけで再コンパイルできます。

- `build.bat` をダブルクリック
- または PowerShell で `.\build.ps1` を実行
